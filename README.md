# software-testing-learning
第一次使用GitHub

这是我的第一个 GitHub 仓库，用于记录软件测试学习过程。

## 学习内容

仓库与提交
    ↓
Issue
    ↓
分支
    ↓
Pull Request
    ↓
GitHub Desktop
    ↓
自动化测试项目
    ↓
参与别人的开源项目
saucedemo-testing-project
针对公开演示网站完成：
- 测试计划
- 登录、购物车、下单测试用例
- Bug 报告
- Playwright 或 Selenium 自动化测试
- 测试执行报告

api-testing-project
针对公开 API 完成：
- 接口测试用例
- Postman 集合
- Python + pytest 自动化
- 参数化测试
- HTML 或 Allure 测试报告

qa-toolbox
自己开发一个测试小工具，例如：
- 测试数据生成器
- JSON 格式化工具
- 接口响应对比工具
- 日志分析工具

参与开源项目
在别人的项目中：
- 提交有效的 Issue
- 复现 Bug
- 完善文档
- 补充测试用例
- 提交 Pull Request
